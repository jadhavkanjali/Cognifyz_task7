# Cognifyz Technology – Task 7

**Created by:** Anjali Jadhav

## About
A student registration form built to demonstrate inline CSS, JavaScript client-side validation, and server-side validation using Node.js and Express.

## Features
- Responsive registration form
- Client-side and server-side validation
- Success and error messages
- Temporary in-memory storage

## Technologies
HTML, CSS, JavaScript, Node.js, Express.js

## Run Locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm start`.
4. Visit `http://localhost:3000`.

**Note:** Registration data is cleared when the server restarts.
